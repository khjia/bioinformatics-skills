# Bulk RNA-seq 论文报告：字段、口径与证据

## 逐样本表 S1

| 字段 | 如何报告与复核 |
|---|---|
| 样本、分组、时间、重复、批次、输入文件 | 合并用稳定 ID；以实际进入分析的集合为准。双端记录 R1/R2，但不把原始序列复制进报告。 |
| Raw / Clean reads | 同单位、同样本，双端项目说明是否 R1 与 R2 合计。不要把 reads 和 read pairs 混算。 |
| Raw / Clean bases | 导出保留整数。正文可用 Gb（总碱基数 ÷ 10⁹），不等同压缩文件大小。保留率用 clean bases ÷ raw bases，注明是否按碱基还是 reads。 |
| Raw / Clean Q20、Q30、GC | 各写百分数。Q20 / Q30 是达到相应 Phred 阈值的**碱基**比例，不是 reads 比例；GC 说明来源与分母。依据运行日志实际字段，不假定清洗后一定更高。 |
| Mapping | 逐样本给总体比对率，注明 mapper、参考、是否按 reads 或 read pairs。可得时另保留 mapped reads 和被送去比对的 reads。BAM FLAG 百分比、唯一比对比例、正确配对率和计数分配率是不同指标。 |

**总体 mapping（按 reads 加权）** = `100 × ∑ mapped_reads / ∑ mapping_input_reads`。样本均值/中位数/范围另列，不能混称总体。找不到精确计数时，不从四舍五入的百分比反推整数；可汇报样本中位数/范围并注明覆盖，不能把只覆盖部分样本的加权率写成全体。比对器的分母与 clean reads 不同，核对是否存在额外过滤或单位错误，不能静默统一。

## 每步要写什么

| 步骤 | 方法与过滤 | 结果和建议图 |
|---|---|---|
| 输入与清洗 | 样本数、布局与读长、软件版本；写清实际执行的接头修剪、碱基质量、N、最短长度等条件，区分显式参数和未知默认值。 | Raw/Clean 汇总、表 S1、必要时清洗前后并列或每样本散点。 |
| 参考比对 | mapper、参考组装及注释版本，是否排除未比对记录、主/次比对的口径。 | 总体与分组统计，每样本的分布或时间图；样本剔除有明确依据。 |
| 定量 | 注释特征与 ID、片段或 reads、链特异设置、输入矩阵与低表达过滤；计数设置不等于验证了建库链特异性。 | 报过滤前后基因数及矩阵列数；说明 counts 和 TPM 哪一个用于哪步。 |
| PCA 与差异 | 变换、特征选择、比较方向与样本数、模型和多重校正；说明阈值仅是后筛选还是模型检验原假设。 | PCA、差异计数、火山图或基因热图；同一 PCA 的坐标与方差比例一起报告。筛选火山图对比时写清选择规则。 |
| 富集与共表达（仅有产物时） | 前景、背景、方向、注释版本、检验和阈值；网络列样本、输入过滤、相关阈值和敏感性。 | 富集图用分母明确的命中比例或校正后 p 值；网络展示支持现有结论的图，不以相关性替代直接调控证据。 |

## 表头与脚本

复制 [`assets/table-s1-rnaseq-qc.tsv`](../assets/table-s1-rnaseq-qc.tsv) 的表头，按样本填值。缺失的数值用 `NA`；不要把缺失写成 0。列名中 `_pct` 为 0–100 尺度，不含 `%`。`mapping_pct` 为日志百分数，`mapped_reads` 和 `mapping_input_reads` 都用未四舍五入的整数且须同口径。可按项目附加元数据列。

对生成的 TSV 运行包内脚本（从 Skill 根目录明确传入表路径）：`python -I scripts/validate_rnaseq_qc.py /path/to/table-s1.tsv`。可追加 `--expected-samples /path/to/sample-ids.txt`，文件一行一个样本 ID、不带表头。脚本只查字段逻辑与汇总，不读取 FASTQ、不修改文件、不上传，也不证明原始分析可靠。精确加权率只在对应分子/分母覆盖全部样本时输出。

## 可参考的发表与归档资料

- [Li 等，IJMS 2023，表 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC9963955/)：植物 RNA-seq 逐样本测序量、Q20/Q30、GC 与 mapping 的表格示例。
- [Conesa 等，RNA-seq 实践综述](https://doi.org/10.1186/s13059-016-0881-8)：从原始 QC 到统计的流程与诊断。
- [NCBI GEO 测序数据提交要求](https://www.ncbi.nlm.nih.gov/geo/info/seq.html)：若使用 GEO，核对元数据、原始 reads 和处理后数据；文章的可用性声明与归档号以实际提交状态为准。
