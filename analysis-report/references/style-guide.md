# 分析报告写作细则

## 1. 摘要

一张表概括全流程，三列足够：

| 步骤 | 做了什么 | 关键结果 |
|---|---|---|
| 1 | fastp 质控 | 103.1 Gb，Q30 96.36% |
| 2 | HISAT2 比对 | 98.40% |

摘要里不要出现方法学争论或局限性（放讨论）。数字用最终值，不要写"约"。

## 2. 步骤内三段式

### ### 材料方法

写四类信息，缺一不可：

1. **软件与版本**：`fastp 1.3.3`、`DESeq2 1.x`、`iTAK v2`
2. **关键参数**：命令行参数或函数参数，只写影响结果的（如 `--length_required 60`、
   `padj < 0.05 且 |log2FC| > 1`）
3. **输入与阈值来源**：输入文件是什么、阈值怎么来的
   - 软件推荐值 → 写"官方 Cutoff 推荐 0.94，实际采用 0.90（原因见下）"
   - 人为设定 → 写清楚并给理由
4. **产出物**：这一步输出了什么（矩阵、BAM、表）

写法建议用短句 + 列表，不要写成段落：

```markdown
- 软件：**fastp 1.3.3**
- 参数：`--thread 4 --length_required 60`
- 输入：双端原始 fastq
- 输出：clean fastq + JSON/HTML 质控报告
```

### ### 结果

- 只放**可以核对的事实**：统计表、图
- 表用 `kable()`，图用 `![]()`，图前或图注里必须有编号
- 表标题写清楚单位（M = 百万 reads；Gb = 十亿碱基）
- 不在这里解释"为什么"，不写"说明…"

### ### 解读

固定以 `**解读**：` 开头，2–4 句，回答三个问题：

1. **数字说明什么**（把数字翻译成状态）："Q30 全部高于 95.8%、样本间极差 0.4 个百分点，
   说明建库质量稳定"
2. **能推出什么结论**（下一步的依据）："因此无需剔除样本，可直接进入比对"
3. **有什么保留**（局限、偏差、与预期的差异）："但该过滤规则对单时间点爆发基因偏严格"

写法对比：

| ❌ 不合格 | ✅ 合格 |
|---|---|
| 比对率 98.4% | 比对率 98.2%–98.6%，样本间极差仅 0.4 个百分点，说明建库与参考基因组匹配稳定，无样本需剔除 |
| 富集到光合作用 | 前期的光合作用条目 28 个基因全部命中（28/28，FDR = 2.4e-9），说明这是整条通路被同步激活，而不是零星基因 |

**不许超纲**：解读里出现的每个判断都要有本步骤的数据支撑，不能拿后文的结论倒推。

## 3. 图表规范

- 每张图必须能被单独看懂：图注包含对象、坐标轴含义、颜色/大小映射、n
- 同一份报告内图号连续；正文引用"图 N"
- 表号连续；表标题在表**上方**（kable caption 默认在上）
- 数值精度统一：百分比 1–2 位小数，p 值用科学计数法或 `1.2e-5`
- 不要出现"见上图/下表"这类相对指代，用编号

## 4. 语言

- 中文正文，英文术语与软件名保留原文
- 数字与单位之间留空格：`103.1 Gb`、`15 个样本`
- 避免"我们"开头；用"本分析/本报告"
- 避免营销式形容：不用"显著提升""完美""极大"，用具体数字
- 结论句用"说明/提示/表明"，不用"证明"（相关≠因果）

## 5. 讨论与局限

固定写 4–6 条，每条一段，覆盖：

1. 方法学选择带来的偏差（阈值、参数、近似实现）
2. 结论的适用边界（相关 vs 因果、样本量、单一条件）
3. 已知的注释/数据库假象（如植物基因映射到动物疾病通路）
4. 未做但应该做的验证实验

## 6. 软件与版本

汇总表，与各步骤"材料方法"里写的版本**必须一致**：

| 步骤 | 软件 | 版本 |
|---|---|---|

R 包版本用 `sessionInfo()` / `packageVersion()` 现取，不要凭记忆写。

## 7. 文件清单

| 文件 | 内容 |

列出报告引用到的全部中间结果与图，路径用相对路径。

## 8. 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 只写结果不写软件/参数 | 无法复现 | 材料方法补齐 |
| 结果与解读混写 | 读者分不清事实与推断 | 拆成两段 |
| 正文数字与表不一致 | 一眼被看出没核对 | 用 chunk 直接算，不手写 |
| 图孤儿（未被引用） | 排版断裂 | 加图号与引用句 |
| 写绝对路径/服务器账号 | 泄露环境、换机打不开 | 用相对路径 |
| `format(x, digits = 0)` | `invalid value 0 for 'digits'` 渲染失败 | `format(round(x), big.mark = ",")` |
| pandoc 不在 PATH | `pandoc version 1.12.3 or higher is required` | 渲染前 `export PATH=...` |
| 先过滤再算 TPM/CPM | 分母变了，数值全错 | 先算归一化再过滤 |

- [ ] 所有阈值都交代了来源（软件推荐 / 文献 / 自选 + 理由）
- [ ] 正文中的每个数字都能在表里找到

- [ ] 讨论里写了方法学局限，没有把相关写成因果
- [ ] 全文无服务器路径、无账号、无 IP
