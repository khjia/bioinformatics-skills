# TO-GCN：时间有序基因共表达网络分析（中文说明）

本 skill 指导如何从**时间序列 RNA-seq 数据**（如根/组织发育）构建**时间有序基因共表达网络（Time-Ordered Gene Coexpression Network, TO-GCN）**，把基因按调控层级排成时间顺序，揭示发育过程中基因调控的级联关系。

## 适用场景

- 用户有**时间序列**数据（多个时间点的样本），而非简单的对照比较
- 想从发育/时序表达中推断基因调控层级（哪些转录因子在上游/下游）
- 单条件时间序列 → 用单组或双组（复制数据）流程均可

## 核心流程

```
Step0 数据准备     表达矩阵 + 转录因子注释（iTAK）
Step1 阈值计算     Cutoff → 正/负共表达阈值（p<0.05）
Step2 构建网络     GCN → 转录因子×基因共表达网络
Step3 时间分层     BFS 从种子基因出发，分配 Level（L1→L13）
Step4 热图验证     验证分层是否符合发育先后（对角模式）
Step5 网络可视化    双环同心圆图（内环=TF，外环=结构基因）
Step6 阶段富集     前/中/后期 GO+KEGG 富集 + 多组气泡图
Step7 生成报告     HTML 报告 + report_bundle.tar.gz
```

## 关键要点

1. **双组与单组共用同一流程**：单组数据可复制成两份（C1=C2）跑双组命令，C1+C2+ 等价于单组正共表达，这是用户熟悉的花生流程。
2. **基因编号统一**：TO-GCN 用 `char GID[20]`，基因 ID 超 19 字符会栈溢出崩溃。必须去掉 `gene.` 前缀和 `.mRNA1` 后缀。
3. **网络规模控制**：目标 8000-10000 基因，通过提高 PCC 阈值（如 0.93）实现，但需提示用户取舍。
4. **单种子基因**：用一个代表性转录因子种子（高连接度 + 早期高表达），避免多种子压平层级。
5. **C++ BFS 太慢**：大规模网络用 R/igraph 复现 BFS（O(V+E)，秒级）。
6. **富集图样式**：多组比较用 **x=Group 多组气泡图**（点=Count，色=-log10 p.adjust，蓝→红），不用 facet 分列。
7. **报告面向小学生**：所有概念用打比方讲清楚，数据流程完整可追溯，软件写版本号。
